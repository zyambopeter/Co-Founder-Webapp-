
# Co-Founder Elite AI Website

The official website and web application for Co-Founder Elite AI.

## Mission

Help founders plan, build, launch, and grow businesses using AI-powered tools, workflows, and specialist agents.

## Technology stack

- Next.js
- TypeScript
- Tailwind CSS
- Motion
- Supabase
- GitHub
- Vercel
- RevenueCat, subject to verification of web subscription support

## Development principles

- Keep website code inside this directory.
- Do not overwrite or delete existing project files.
- Never expose private API keys in browser code.
- Protect user data and enforce authorization on the server.
- Build responsive, accessible interfaces.
- Respect reduced-motion preferences.
- Never use fake testimonials, statistics, or product claims.

## Development status

Phase 1: Website foundation.

The website will be implemented incrementally, tested, and prepared for deployment.
